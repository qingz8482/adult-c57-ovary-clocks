# Reproducibility boundary

This is a code-availability release. It provides the canonical analysis code, public annotations, frozen split/fold assignments, environment specifications, workflow documentation, and synthetic smoke tests.

It intentionally excludes large expression inputs, trained models, complete generated result trees, publication PDFs, manuscript drafts, archives, local environments, and third-party software. Full numerical reproduction requires reconstructing the prepared matrices from the cited public datasets and using the final publication release tag.

Synthetic tests validate deterministic fitting behavior and repository plumbing; they do not reproduce or validate biological conclusions. External-projection ages, delta ages, and matched-control differences are descriptive deployment outputs rather than uniformly independent estimates of biological age acceleration.
